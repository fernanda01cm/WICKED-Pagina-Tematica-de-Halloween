# WICKED-Pagina-Tematica-de-Halloween
O WICKED é um projeto de desenvolvimento web com temática de Halloween, criado para apresentar conteúdos relacionados à celebração, incluindo filmes, livros, lendas, história e curiosidades.
A página foi desenvolvida como atividade acadêmica, com foco na prática de HTML, na utilização do framework Bootstrap e na implementação de componentes para organização e interação com o conteúdo.

Objetivos
Praticar a estruturação de páginas web com HTML.
Utilizar componentes do Bootstrap para organizar o layout.
Explorar recursos de responsividade.
Desenvolver uma interface com navegação e seções temáticas.
Utilizar componentes interativos, como carrossel, acordeão, modal e menu lateral.
Trabalhar com ícones e elementos visuais para melhorar a apresentação do site.

Tecnologias utilizadas
HTML5: estruturação do conteúdo da página.
Bootstrap: layout, responsividade e componentes de interface.
JavaScript: funcionamento dos componentes interativos do Bootstrap.
Font Awesome: utilização de ícones.
Funcionalidades
Barra de navegação responsiva.
Campo de pesquisa visual.
Carrossel de imagens.
Cartões com conteúdos sobre filmes, livros e lendas.
Painel lateral (offcanvas) com conteúdo temático.
Seções informativas sobre a história e as tradições do Halloween.
Acordeão com curiosidades.
Componentes de modal e indicador de carregamento (spinner).

Pré-requisitos
Navegador atualizado.
Arquivos do projeto extraídos e organizados corretamente.
As bibliotecas necessárias estão incluídas nos arquivos do projeto. Não é necessário instalar dependências adicionais para abrir a página localmente.

Como executar
Baixe ou clone o repositório.
Extraia os arquivos, caso estejam compactados.
Mantenha as pastas e os arquivos originais na mesma estrutura.
Abra o arquivo index.html em um navegador.
Para garantir o funcionamento correto da página, não remova as pastas de CSS, JavaScript, imagens e Font Awesome.

Demonstração
O projeto pode ser visualizado localmente por meio do arquivo index.html.
Futuramente, o site poderá ser publicado pelo GitHub Pages, permitindo que outras pessoas acessem a página diretamente pelo navegador.
